# Basic Network Commands – Computer Networks Lab

## 1. ipconfig
Displays the IP configuration details of a computer.

```cmd
ipconfig
```

## 2. ping
Checks network connectivity between two devices.

```cmd
ping 192.168.10.1
```

## 3. tracert
Traces the route taken by packets to reach a destination.

```cmd
tracert google.com
```

## 4. nslookup
Finds the IP address associated with a domain name.

```cmd
nslookup google.com
```

## 5. netstat -an
Displays active network connections and listening ports.

```cmd
netstat -an
```

## 6. arp -a
Displays the ARP table containing IP and MAC address mappings.

```cmd
arp -a
```

## 7. hostname
Displays the name of the local computer.

```cmd
hostname
```

## 8. route print -4
Displays the IPv4 routing table.

```cmd
route print -4
```

## 9. getmac
Displays the MAC addresses of network adapters.

```cmd
getmac
```

## 10. pathping
Traces the route and measures packet loss and network latency.

```cmd
pathping 192.168.10.1
```
